# Security & Privacy Model — ScanSocial

## 1. Network Boundary Security
- **Strict Loopback Binding:** The FastAPI application binds exclusively to `127.0.0.1`. Interface exposure on `0.0.0.0` is blocked at startup.
- **Dynamic Ephemeral Session Token:** A 256-bit entropy random token is generated by the desktop supervisor and provided to the backend at launch. Any request missing or with an incorrect `X-App-Session-Token` header receives an immediate `403 Forbidden` response.

## 2. Secrets & Credential Management
- No plain-text storage of cookies, tokens, or AI API keys in SQLite or configuration files.
- The system delegates to the native operating system key vault:
  - **Windows:** Windows Credential Manager (`wincred`).
  - **Linux / Ubuntu:** Secret Service API via `libsecret`.
  - **Fallback:** AES-256-GCM encrypted local vault using a machine-derived master key.

## 3. PII & Data Provenance Protection
- Vietnamese phone numbers must include strict provenance metadata: `source_type` (e.g. `FACEBOOK_POST`), `source_url`, `captured_at`, and `is_verified`.
- No phone guessing or hidden digit inference is permitted.
- Soft-delete ensures inadvertent customer deletion can be reversed, while hard-delete requires explicit double-confirmation.
